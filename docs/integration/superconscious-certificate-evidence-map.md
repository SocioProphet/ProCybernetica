# Superconscious Certificate Evidence Map

Status: Draft v0.1

This document maps completed Superconscious cognition and certificate artifacts into ProCybernetica governance evidence. The mapping preserves repository boundaries: Superconscious produces cognition and certificate artifacts; ProCybernetica defines evidence, safety-case, non-claim, and promotion semantics; AgentPlane owns execution/replay evidence; SourceOS owns lower-level typed substrate contracts.

## Bridge

```text
Superconscious artifact
  -> ProCybernetica evidence receipt
  -> cybernetic safety case
  -> promotion or quarantine decision
  -> AgentPlane replay/evidence reference
  -> SourceOS typed receipt reference where applicable
```

## Required target schemas

The first implementation should wait for stable Tier 1 schema names from #26, especially authority chain, action trace, side-effect assessment, off-history evidence, evidence receipt, promotion decision, cybernetic safety case, release delta report, privacy evidence classification, and authority graph snapshot.

## Validator obligations

The first validator pass should include fixtures for valid synthetic certificate evidence, missing non-claims, promotion without receipt, blocked handoff retained as off-history, trust-surface evidence, runtime claim where only fixtures exist, missing digest, and missing authority chain.

## Non-claims

Synthetic fixtures do not prove live behavior. Certificates do not promote themselves. Public notes are assurance projections, not raw evidence bundles. A benchmark pass does not authorize runtime mutation without policy and promotion gates.

## Closing rule

Superconscious may generate cognition and interpretability evidence. ProCybernetica decides what that evidence means in a governed system.
