# ProCybernetica Standards

This directory is the canonical standards surface for ProCybernetica governance semantics.

## Scope

These standards define the language, proof hygiene, schema invariants, and replay constraints for governed cybernetic systems.

Initial tranche:

1. Notation reservations.
2. Theorem-status taxonomy.
3. Theorem-audit register.
4. Governance-attestation substrate slice.
5. Governance substrate schema enforcing token intersection.

## Gated adoption rules

No governance tooling is authoritative until the notation, theorem-status, theorem-audit, and governance-substrate standards are present.

No replay claim is authoritative until canonical forms, deterministic cleavage, and cleavage versioning are specified.

No evidence aggregate may be called a colimit until a colimit witness proves the universal property naturally in the target object.

## Canonical operating questions

Every governance, token, policy, authority, evidence, replay, or projection change must answer:

1. Which object of `W_gov` does it modify?
2. Which policy object in `Pol` governs it?
3. What is its vertical component?
4. What is its cartesian / reindexing component?
5. Which evidence cocone receives its trace?
